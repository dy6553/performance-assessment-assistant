# 수행도우미 로컬 저장·출처 검증·제출 준비 계획

- 작성일: 2026-09-05
- 상위 공통 계획: 시험온 저장 방식과 동일한 Local-first 원칙을 적용한다.

## 목표

수행평가 결과를 생성한 뒤 휴대폰에 자동 저장하고, 저장 성공이 확인되면 서버의 생성 결과와 업로드 원본을 즉시 삭제한다. 사용자는 오프라인에서도 주제 선정부터 완성본까지 다시 열어 수정하고 PDF·DOCX로 보관할 수 있다.

## 작업 순서

| 단계 | 기능 | 상세 작업 | 완료 기준 |
|---|---|---|---|
| 1 | 기기 자료함 | 수행평가별 제목·과목·생성일·현재 단계를 표시하는 자료함 | 저장한 수행평가를 목록에서 열기·삭제 가능 |
| 2 | 단계별 자동저장 | 주제, 개요, 초고, 완성본, 선택 반영한 AI 수정 내용을 300~500ms 지연 저장 | 새로고침·오프라인에서도 마지막 작업 상태 복원 |
| 3 | 서버 삭제 안전장치 | 로컬 저장 성공 확인 후 DB·Storage의 생성 결과와 업로드 원본 삭제 | 저장 실패 시 서버 삭제 금지, 복구 안내 표시 |
| 4 | 자료 조사·출처 검증 | 주제 확정 뒤 자료 URL·DOI와 인용 정보를 관리하고 확인이 필요한 출처 표시 | 참고문헌 목록과 본문 인용을 연결 |
| 5 | 일정 연결 | 마감·발표·중간 점검을 캘린더와 단계별 할 일에 연결 | 현재 단계와 다음 마감이 화면에 표시 |
| 6 | 제출 전 검사 | 분량·필수 항목·형식·인용/참고문헌 누락을 점검 | 수정할 항목과 이유를 표시 |
| 7 | 문서 내보내기 | PDF·DOCX 미리보기와 다운로드 | 휴대폰 파일 앱 및 한글·Word에서 파일 열기 가능 |

## 저장 기준

- 브라우저의 IndexedDB와 OPFS에 문서 본문·버전·메타데이터를 저장한다.
- 기기 자료는 ownerId로 분리하여 다른 계정과 섞이지 않게 한다.
- 교차 서비스 데이터 공유는 하지 않는다.
- 중요한 문서는 PDF 또는 DOCX로 별도 저장하도록 안내한다. 브라우저 데이터를 삭제하거나 기기를 바꾸면 로컬 자료가 사라질 수 있기 때문이다.
- 서버 AI 요청에는 생성에 필요한 자료만 전송하고 결과는 장기 보관하지 않는다.

## 검증 기준

1. Android Chrome과 Samsung Internet에서 오프라인 열기와 수정이 가능하다.
2. 로컬 저장 성공 뒤 서버 자료가 삭제되고, 실패 시에는 삭제되지 않는다.
3. 같은 기기에서 계정을 바꾸면 이전 계정의 수행평가가 보이지 않는다.
4. 모바일 화면에서 입력·저장·다운로드 버튼이 가려지지 않는다.
5. PDF·DOCX가 휴대폰에서 정상적으로 열리고, DOCX는 한글에서 수정 가능하다.

## 휴대폰 내장공간 사용 보완

### 저장 위치와 역할

| 위치 | 저장 대상 | 사용자에게 보이는 위치 | 관리 방식 |
|---|---|---|---|
| 앱 내부 저장소 | 문제·수행평가 본문, 풀이 기록, 단계별 버전, 임시 파일 | 앱의 내 자료함 | IndexedDB·OPFS로 관리 |
| 휴대폰 다운로드 폴더 | 사용자가 보관하려는 PDF·DOCX | 파일 앱의 다운로드 폴더 | 사용자가 파일 앱에서 이동·공유·삭제 |

### 저장 전 확인

1. 생성 결과를 저장하기 전에 Storage API로 사용 가능 용량을 확인한다.
2. 예상 저장 크기를 계산해, 남은 공간이 부족하면 저장을 시작하지 않고 필요한 공간과 정리 방법을 안내한다.
3. 큰 원본 파일은 로컬 저장 후에도 용량이 큰 순서로 표시하고, PDF·DOCX로 내보낸 뒤 원본을 지울 수 있게 한다.

### 기본 용량 정책

- 텍스트·문제·수행평가 문서는 일반적으로 적은 용량이므로 자동저장한다.
- 이미지·PDF·스캔 원본은 선택 저장으로 두고, 기본적으로 AI 처리 완료 뒤 서버와 기기 임시본에서 삭제한다.
- 기기 내 자료함의 기본 목표 용량은 300MB로 두며, 사용자가 설정에서 변경할 수 있게 한다.
- 목표 용량의 80%에 도달하면 경고를 표시하고, 100%에 도달하면 새 대용량 자료 저장 전 정리를 요구한다.
- 최근에 열지 않은 자료, 완료된 생성 작업의 임시 파일, 내보내기 뒤 보관 확인된 원본 순서로 정리 제안을 한다.

### 삭제와 복구 안전장치

1. 사용자가 서버 즉시 삭제를 선택해도 휴대폰 저장 성공 확인 전에는 DB와 Storage를 삭제하지 않는다.
2. 앱 내부 자료 삭제는 먼저 휴지통으로 이동하고 7일 뒤 완전 삭제한다.
3. 사용자가 다운로드한 PDF·DOCX는 휴대폰 파일 앱의 파일이므로 앱에서 자동 삭제하지 않는다.
4. 브라우저 데이터 삭제·앱 초기화·기기 교체 시 로컬 자료가 사라질 수 있음을 자료함과 내보내기 화면에 표시한다.

### 검증 추가

1. 저장 공간 부족 상황에서 서버 자료가 먼저 삭제되지 않는지 확인한다.
2. 300MB 제한 근처에서 경고·정리·재저장이 정상 동작하는지 확인한다.
3. 원본 파일 삭제 뒤 문제·수행평가 본문과 내보낸 PDF·DOCX가 정상적으로 열리는지 확인한다.
4. Android Chrome과 Samsung Internet에서 저장 용량 표시가 지원되지 않을 때도 안전한 기본 한도로 작동하는지 확인한다.
