# AI 모델 자동 승인 기준 완화 (2026-09-07)

## 배경

관리자 화면이 `enabled && production_approved`만 집계하여, 이미 종료되어 NVIDIA 카탈로그에서 사라진 모델도 승인 모델 수에 포함했다. 실제 라우터는 `catalog_available`과 `deprecated`까지 확인하므로 화면의 3개와 실제 사용 가능한 1개가 일치하지 않았다.

## 변경 내용

- 관리자 대시보드는 현재 카탈로그에 있고 폐기되지 않은 모델만 `현재 사용 가능`으로 집계한다.
- 자동 승인 내부 평가 최소 점수를 0.80에서 0.75로 완화했다.
- NVIDIA 공식 모델 페이지와 Model Card를 모두 요구하지 않고 둘 중 하나를 확인하면 된다.
- 수학·과학·사회 문항 전체 통과는 참고 평가로 유지하되 승인 필수 조건에서는 제외했다.
- 실제 API 호출, 구조화 JSON, 한국어 이해, 환각 방지, 제공 자료 충실도는 필수 조건으로 유지했다.
- 자동 검토 대상을 하루 최대 30개로 늘리고 5개씩 병렬 평가한다.
- 실제 사용 가능 후보가 5개 미만이면 실패 후보의 재검사 간격을 7일에서 1일로 단축한다.
- 계정별 `/models` 응답에서 빠질 수 있는 NVIDIA 공식 문서 모델을 보조 발견 목록에 넣되, 실호출 검증을 통과하기 전에는 절대 사용하지 않는다.
- 실패 모델을 매일 반복 검사해 새 후보가 밀리지 않도록 재검사 간격을 7일로 제한했다.
- 자동 승인 허용 개발사에 Mistral AI, Cohere, IBM, AI21 Labs, Upstage, NAVER, Rakuten을 추가했다. 중국계 차단 정책은 유지한다.

## 영향

품질과 학생 데이터 보호의 핵심 조건은 유지하면서, 문서 중복 확인이나 일부 과목 문항 실패만으로 정상 작동 모델이 탈락하는 비율을 낮춘다. 실제 승인 수는 매일 NVIDIA 카탈로그에 노출되는 모델과 내부 실호출 평가 결과에 따라 달라진다.
