# 수행도우미 제품 명세

## 제품 개요

수행도우미는 학생이 수행평가 조건을 입력하면 과제 유형 파악, 주제 추천, 작성 전략, 초안 작성, 독립 검증까지 연결하는 모바일 중심 웹 앱이다.

## 핵심 사용자 흐름

1. 수행평가 유형 선택
2. 교육과정, 학교급, 학년, 과목, 교사 안내, 루브릭 입력
3. 주제 직접 입력 또는 AI 추천
4. 필요하면 포함 키워드/요청사항과 난이도 1~7단계를 추가해 다시 추천
5. 입력 내용 최종 확인
6. 작성 전략 생성
7. 초안 생성 후 별도 결과 화면으로 이동
8. 독립 검증 후 별도 검증 결과 화면으로 이동
9. 최근 기록에서 24시간 동안 결과 확인

## 주제 추천

주제 추천은 앞 단계에서 입력한 정보를 그대로 사용한다. 다시 추천할 때는 추가 입력을 최소화한다.

추가 조건은 다음 두 가지다.

- 포함 키워드 / 요청사항
- 주제 수준 1~7단계

제외 키워드 입력은 기본 UI에 두지 않는다.

## 결과 화면

결과 화면은 긴 카드형 UI보다 본문 가독성을 우선한다.

- 전략, 초안, 검증 결과를 한 페이지에 계속 쌓지 않는다.
- 초안과 검증 결과는 각각 별도 화면에서 본다.
- 모바일에서 이전/다음 행동에 쉽게 접근할 수 있어야 한다.
- 복사, 다시 작성, 독립 검증 같은 주요 행동은 결과 근처에 배치한다.

## AI 모델 라우팅

AI 모델은 작업 단계와 과제 문맥에 맞춰 자동 선택한다.

고려 요소:

- 과목
- 학교급/학년
- 수행평가 형식
- 난이도 1~7
- 입력 길이
- 작업 단계
- 빠른 응답 선호

승인되지 않은 모델은 자동 라우팅 후보에 포함하지 않는다.

## 진행 상태

AI 요청에는 다음 상태를 표시한다.

- 현재 작업명
- 진행률 추정 퍼센트
- 예상 남은 시간
- 예상 시간 초과 상태
- 성공/실패 상태

## 최근 기록

- 기록 보존 기간: 24시간
- 분석/초안/검증 결과 상태 확인 가능
- 만료까지 남은 시간 표시
- 24시간 이후 자동 삭제

## 안전성과 사실성

- 외부 확인이 필요한 최신 사실을 임의로 확정하지 않는다.
- 출처가 필요한 항목과 불확실한 항목을 결과에 명시한다.
- 독립 검증은 칭찬보다 요구조건, 논리, 사실/출처, 루브릭 충족 여부 탐지를 우선한다.
