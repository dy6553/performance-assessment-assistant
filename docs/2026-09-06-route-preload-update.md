# 전체 화면 미리 대기 적용

- 구현 날짜: 2026-09-06
- 대상: 수행도우미

## 구현

- 자주 사용하는 주요 화면 코드를 앱 실행 후 백그라운드에서 순차적으로 미리 불러온다.
- 첫 화면 렌더링을 방해하지 않도록 350ms 뒤부터 140ms 간격으로 분산한다.
- 링크에 손가락이나 포인터가 닿거나 키보드 초점이 이동하면 해당 화면을 우선 준비한다.
- 오프라인과 데이터 절약 모드에서는 불필요한 네트워크 미리 불러오기를 하지 않는다.
- AI 모델, 생성 품질, 결과 분량, IndexedDB/OPFS 및 암호화 동기화에는 영향을 주지 않는다.

## 변경 파일

- `src/components/route-preload-runtime.tsx`
- `src/app/layout.tsx`

## 인프라

- Supabase migration 및 RLS 변경 없음.
- Vercel Production build와 실제 URL 응답으로 검증한다.
