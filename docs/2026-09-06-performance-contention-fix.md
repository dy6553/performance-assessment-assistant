# 수행도우미 초기 반응 속도 추가 최적화

- 구현 날짜: 2026-09-06
- 원인: 초기 렌더링과 동시에 다수의 작업 화면 및 전역 AI UI 청크가 경쟁적으로 로드됨

## 변경

- 자동 사전 준비 화면을 16개에서 자주 쓰는 주요 화면 7개로 줄였다.
- 첫 화면 완료 후 1.5초 뒤부터 420ms 간격으로 사전 요청을 분산한다.
- 작업 단계 화면은 사용자가 링크에 접근하는 순간 우선 prefetch한다.
- 전역 AI 도우미와 작업 단계 AI UI를 첫 화면 후 1.2초 지연 로딩한다.
- 암호화 동기화와 local-first 저장은 즉시 시작하는 기존 정책을 유지한다.
- 데이터 절약 모드와 오프라인에서는 자동 사전 요청을 중단한다.

## 품질 및 데이터 영향

- AI 모델, 추론, 프롬프트, 결과 분량 및 생성 품질 변경 없음.
- IndexedDB, OPFS, 암호화 동기화, RLS 및 수동 백업 변경 없음.
- Supabase migration 없음.
