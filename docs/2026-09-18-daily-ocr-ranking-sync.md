# 2026-09-18 OCR 모델 순위 동기화

- 시험온의 매일 갱신된 실측 OCR 순위를 공유 API에서 읽는다.
- 공유 API의 `primary`는 현재 벤치마크를 통과한 실측 1위이며, `verification`은 실측 2위가 있을 때만 값이 들어간다.
- 수행도우미는 실측 2위가 아직 없어도 실측 1위를 버리지 않고 즉시 평가기준표·안내서 OCR의 기본 모델로 사용한다.
- 독립 검증은 공유 API가 실제 실측 2위를 제공하고 그 모델이 수행도우미 로컬 Registry에서도 운영 승인 상태일 때만 실행한다.
- 임시 fallback 모델은 1차 호출 장애 복구에는 사용할 수 있지만 실측 2위나 검증 모델로 표시하지 않는다.
- 공유 순위에 포함된 모델도 수행도우미 로컬 Registry의 `enabled=true`, `production_approved=true` 조건을 다시 통과해야 사용한다.
- 시험온 공유 순위 조회 실패 또는 로컬 Registry 확인 실패 시 기존 환경설정 기반 비전 모델로 판독해 서비스 중단을 피한다.
- 시험온의 모델 카탈로그는 00:00 UTC, 한국어 OCR 벤치마크는 01:00 UTC에 실행한다. 수행도우미 승인 목록 동기화는 03:00 UTC에 실행해 갱신 순서를 확보한다.
- 벤치마크에는 한국어 문항, 수식, 표, 작은 손글씨, 별표, 형광펜 표시가 포함되고 항목별 최소 기준을 모두 통과한 모델만 순위에 들어간다.

## 현재 동작

- 2026-09-18 기준 시험온에서 확인된 실측 통과 모델은 `google/gemma-4-31b-it`이며 점수는 약 0.9778이다.
- 같은 시점 실측 2위는 확정되지 않았으므로 수행도우미는 해당 1위를 기본 OCR로 사용하고 독립 검증은 생략한다.
- 이후 일일 평가에서 두 번째 통과 모델이 생기면 코드 수정 없이 자동으로 2위 검증 모델을 사용한다.
