# 2026-09-18 OCR 모델 순위 동기화

- 시험온의 매일 갱신된 OCR 기본/검증 모델을 공유 API에서 읽는다.
- 수행도우미 로컬 Registry에서 두 모델의 운영 승인 상태를 확인한 뒤 사용한다.
- 평가기준표와 안내서 OCR을 1위 모델로 판독하고 2위 모델이 원본 이미지와 대조해 검증한다.
- 공유 순위 조회 실패 또는 로컬 동기화 지연 시 기존 모델 설정으로 판독한다.
- 시험온의 모델 카탈로그는 00:00 UTC, 한국어 OCR 벤치마크는 01:00 UTC에 실행한다. 수행도우미 승인 목록 동기화는 03:00 UTC에 실행해 갱신 순서를 확보한다. 새 벤치마크에는 작은 손글씨, 별표, 형광펜, 한국어 문항과 표가 포함된다.

## 초기 기본·검증 모델

- 시험온 공유 API의 임시 기본 `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning`, 검증 `meta/llama-3.2-11b-vision-instruct`를 로컬 운영 승인 여부 확인 후 사용한다.
- 이는 OCR 실측 1·2위가 아닌 초기 지정이며, 일일 평가 결과가 있으면 측정 모델을 우선한다.
