# 2026-09-18 OCR 모델 순위 동기화

- 시험온의 매일 갱신된 OCR 점수 순위를 공유 API에서 읽는다.
- OCR 모델에는 별도의 통과/탈락 품질 기준을 적용하지 않는다. 정상적으로 이미지 판독 결과를 반환해 채점 가능한 모델이면 점수가 낮아도 순위에 포함된다.
- 공유 API의 `primary`는 현재 점수 1위, `verification`은 현재 점수 2위다.
- 수행도우미는 점수 1위를 평가기준표·안내서 OCR의 기본 모델로 사용하고, 점수 2위를 원본 이미지 대조용 독립 검증 모델로 사용한다.
- 시험온에서 과거 `MINIMUM_CRITERIA`로 기록된 모델도 실제 점수가 있으면 새 정책에서는 순위에 포함된다.
- NVIDIA 호출 실패, 타임아웃, 비정상 JSON처럼 채점 자체가 불가능한 모델만 순위에서 제외한다. 이는 품질 컷이 아니라 측정 실패 처리다.
- 공유 순위에 포함된 모델도 수행도우미 로컬 Registry의 `enabled=true`, `production_approved=true` 조건을 다시 확인한 뒤 사용한다.
- 시험온 공유 순위 조회 실패 또는 로컬 Registry 확인 실패 시 기존 환경설정 기반 비전 모델로 판독해 서비스 중단을 피한다.
- 시험온의 모델 카탈로그는 00:00 UTC, 한국어 OCR 점수 평가는 01:00 UTC에 실행한다. 수행도우미 승인 목록 동기화는 03:00 UTC에 실행한다.
- 점수는 한국어 문항 20%, 손글씨 20%, 형광펜 15%, 별표 10%, 표 20%, 수식 10%, 문항 번호 5% 가중치로 계산된다.

## 현재 정책

- 최소 점수나 항목별 합격선 없이 점수만 비교한다.
- 점수 내림차순으로 1위와 2위를 자동 선택하며 동점이면 응답 시간이 짧은 모델을 우선한다.
- 수행도우미 코드는 시험온 공유 API를 실시간으로 읽기 때문에 시험온의 새 점수 정책이 별도 코드 변경 없이 바로 반영된다.
