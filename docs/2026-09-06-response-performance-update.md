# 반응 속도 최적화

- 구현 날짜: 2026-09-06
- 목표: AI 결과 품질과 기능 제한 없이 수행도우미의 체감 반응 속도 개선

## 변경 내용

- 빠른 반응 모드를 신규·초기화 사용자에게 기본 적용했다.
- 빠른 반응 모드는 UI 전환 시간만 줄이며 AI 요청에 속도 우선 헤더를 보내지 않도록 분리했다.
- 따라서 AI 모델 선택, 추론 수준, 결과 분량과 품질 기준은 기존 일반 모드와 동일하다.
- 로그인 사용자의 관리자 권한 확인과 학교 범위 프로필 조회를 병렬화해 서버 렌더링 대기 시간을 줄였다.
- 사용자가 명시적으로 빠른 반응 모드를 끈 경우에는 기존 전환 효과를 유지한다.

## 데이터 및 인프라 영향

- IndexedDB, OPFS, 암호화 동기화 및 수동 백업 동작 변경 없음.
- Supabase migration 및 RLS 변경 없음.

## 검증

- 정적 검사 및 자동 테스트
- Vercel Production build
- Production READY 상태 및 실제 URL 응답
