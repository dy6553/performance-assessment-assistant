# 기기 저장공간 기능 구현 기록

## 적용 내용

- 수행평가 프로젝트, 초안, 완성본, AI 대화와 업로드 원본을 브라우저의 IndexedDB 또는 OPFS에 저장한다.
- 기본 저장 한도는 300MB이며 사용자가 50~2,000MB 범위에서 바꿀 수 있다.
- 저장 전 브라우저 전체 사용량과 앱 한도를 확인하고 공간이 부족하면 기존 자료를 보존한 채 저장을 중단한다.
- 프로젝트 삭제 시 7일간 휴지통에 보관하고 복원을 지원한다.
- 7일이 지난 프로젝트는 연결된 대화와 업로드 파일까지 함께 정리한다.
- 자동 저장 실패 상태를 화면에 표시해 사용자가 저장공간을 확인할 수 있게 한다.

## 서버 데이터 원칙

수행도우미의 개인 수행평가 본문과 생성 결과는 서버 DB에 영구 저장하지 않는다. API 응답을 받은 뒤 기기에 저장하며, 기존 로컬 중심 구조를 유지한다.
