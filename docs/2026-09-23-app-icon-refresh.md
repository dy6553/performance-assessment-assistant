# 앱 아이콘 리프레시 — 2026-09-23

## 변경 내용

- 수행도우미 앱 아이콘을 보라→하늘 그라데이션 기반의 새 브랜드 아이콘으로 교체했습니다.
- 체크리스트 + AI 스파클 심볼로 수행평가 관리와 AI 지원 기능을 함께 표현했습니다.
- 시험온과 동일한 둥근 그라데이션 배경·굵은 흰색 심볼 계열을 사용해 제품군의 시각적 일관성을 높였습니다.
- PWA 매니페스트는 SVG 벡터 아이콘과 192×192·512×512 PNG 폴백을 함께 제공하며, 512 PNG를 maskable 아이콘으로도 지정했습니다.
- 서비스 워커 쉘 캐시를 v4로 올려 기존 설치 환경에서도 새 매니페스트와 아이콘을 다시 받도록 했습니다.

## 영향 범위

- 브라우저 탭 아이콘
- Android/Chromium PWA 설치 아이콘
- PWA 매니페스트 및 설치 화면
- 기존 기능/API/데이터베이스 로직에는 변경 없음

## 참고

192/512 PNG도 새 디자인으로 교체해 PWA 설치·Apple 홈 화면·구형 아이콘 경로가 모두 같은 브랜딩을 사용합니다. SVG는 해상도 독립 기준 소스로 유지합니다.
