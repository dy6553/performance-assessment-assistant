# 요청사항·진로 접기·과제 문서 백엔드 변환

- 구현 날짜: 2026-09-07
- 대상: AI 주제 추천 및 모든 수행평가 시작 화면

## UI 변경

- AI 주제 추천 화면에 독립된 요청사항 입력칸을 추가했다.
- 진로 입력 영역과 작업별 진로 연계 선택을 접기/펼치기 구조로 변경했다.
- AI 주제 추천 화면에도 평가기준표·수행평가 안내표 업로드를 추가했다.
- 기존 보고서·발표·탐구·자동분석 시작 화면도 공통 업로드 컴포넌트와 접이식 진로 선택을 사용한다.

## 파일 처리

- PDF, JPG, JPEG, PNG, WebP를 지원한다.
- 원본은 local-first 정책에 따라 OPFS 또는 IndexedDB에 먼저 저장한다.
- PDF와 사진의 변환·판독은 Node.js 백엔드 API에서 수행한다.
- 파일당 최대 4MB, 한 번에 최대 10개를 허용하며 파일 시그니처를 검증한다.
- 응답과 판독 데이터는 private, no-store로 처리한다.

## 인프라

- Supabase migration 및 RLS 변경 없음.
- 기존 암호화 동기화와 .assessment-backup 백업 유지.
