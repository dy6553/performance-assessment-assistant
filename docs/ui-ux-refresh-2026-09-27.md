# 수행평가 도우미 UI/UX 개편

## 변경 화면

- 홈: 새 작업 시작과 세 가지 진입점에 집중하고 최근 작업, 캘린더, AI 도구를 보조 영역으로 이동.
- 만들기: 세 유형 선택 카드의 높이와 설명 밀도를 낮춤.
- 모바일 탐색: 홈, AI, 만들기, 기록, 설정으로 재배치. 캘린더는 홈에서도 접근 가능.
- 과제 입력: 기본 정보와 과제 문서 입력을 두 화면 단계로 분리. 같은 세션의 입력은 유지.
- 작업 영역: 작성 전략, 초안, 검증 결과를 한꺼번에 펼치지 않고 단계 탭으로 구분.
- 설정: 기본, 화면 및 사용성, 알림 및 시작, 데이터, 기타로 그룹화.
- 화면 테마: 라이트, 다크, 시스템 설정 선택. OS 테마 변경 시 앱 내부 화면 및 색상 메타를 갱신.

기존 AI API와 데이터 스키마는 변경하지 않았다. 유형 선택, AI 분석, 주제 추천, 작성, 검증, 기록, 관리자, 계정, PWA 기능의 경로는 보존했다.

## 검증

- `npm run typecheck`
- 변경 파일 ESLint
- `npm run build`

실제 AI 호출은 운영 자격 증명과 입력 문서가 필요하므로 빌드 확인과 별도로 확인해야 한다.
